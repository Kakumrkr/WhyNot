# First-release security review

Scope is the static browser bundle, curated navigation, local snapshot files, patient projection, and packed libraries. The playground is public and serves fictional fixtures. The Staff switch controls what the UI shows. An integration with real records would need its own authorization, storage, and booking controls. [Architecture](../01-architecture.md) · [Integration guide](../integration.md)

| Surface                        | Control and evidence                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Local file parsing             | The browser checks 256 KiB before reading, decodes strict UTF-8, verifies schema version and references, and checks resource counts, candidate count, supported instants and 31 local dates before evaluation. Playwright exercises malformed UTF-8 and JSON, versions, references and ingestion bounds.                                                                                                   |
| Text rendering and I/O         | React renders labels and text as text. The import browser test verifies literal display, zero follow-up network requests, empty web storage, and no URL or history mutation. Export uses a local attachment with a fixed filename. The source review found no application payload logging, outbound input handling, or browser persistence.                                                                |
| Navigation                     | Imported state clears on reset, reload and browser history restoration. A delayed local read could previously reopen a snapshot after pressing Back. The file control now invalidates pending reads on history transitions and the app restores curated state when returning from the browser cache. A browser regression holds the file read across Back and verifies that the later result is discarded. |
| Audience and traces            | Patient views use projected results and public narration. Trace, candidate rows and policy details have staff rendering paths. Projection properties and browser audience switching check private values and reference integrity. Shareable links validate curated parameters.                                                                                                                             |
| Dependency and secret boundary | The boundary tests reject Node imports, fixture imports outside the static adapter, and provider or server modules in the playground. The packed consumer checks each whitelist of entries, files and direct dependencies. The static build requires no environment variables. A pinned production dependency audit returned no known vulnerabilities.                                                     |

The review found no remaining blocker or major issue in this scope. Accepted limits include publicly inspectable fictional assets and local processing time for dense but valid snapshots. The ingestion limits bound input size and scope. The published latency targets apply to the Riverside S workload. Use trusted fictional files, and remember that an explicit export writes a file to your device.
